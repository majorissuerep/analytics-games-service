# Radar retirement, Space Cadet replacement, and Mafia planning QA

11 November 2026.

- Radar's workspace, rules registration, client registry entry, manifest, assistant
  knowledge, live design-reference links, and gameplay tests are removed.
  Tombstones prevent external re-registration. The one-time atomic migration
  deletes only Radar rooms, scores, and external registrations; unrelated Chess
  data is preserved. A temporary-table PostgreSQL test verifies scope and
  idempotence, then rolls back. The retired page responds 410 before streaming;
  leaderboard and create-room APIs reject the removed game.
- Pinball now uses the faithful Space Cadet WebAssembly engine, with CC0 Open
  Cadet data by default as selected by the user. The unrelated lrusso runtime and
  unused original Neon Forge implementation are removed. Runtime/data revisions,
  licenses and checksums are in `public/vendor/space-cadet`; the regenerate/verify
  script never downloads original Microsoft resources.
- Browser checks exercise a rendered native table, new game, launch, flippers,
  pause/resume, persisted opt-in sound, desktop/phone layouts, exit, slow download,
  failed download/retry, and local original-file loading/restoring free play.
  The local-file fixture is CC0 data; no Microsoft fixture is committed. The file
  import path issues no POST/PUT or server upload.
- Mafia's original SVG icon and Coming soon badge appear on the XP desktop;
  its preview is accessible in a window and at `/games/mafia`. It is excluded
  from random installed-game launch and installed counts. Preview checks reject
  any media permission request and verify there is no game iframe/room request.
  No Mafia game, server rule, room API, media account, or paid deployment exists.
- The Mafia architecture includes references, privacy and room contracts, a
  bounded 360p/15 fps media policy, a reproducible 20-person capacity model and
  staged implementation/acceptance gates. A separate real local SFU forwarding
  experiment is recorded with its 40-client publisher/subscriber split and
  limitations. It is not a 20-browser or production-network validation.
- Existing Chess engines, human/free play, arena, private rooms, Minefield,
  Paintbox, Pip, consent and XP/Prism design regressions are retained.

Visual review compares the old unrelated vertical table with the Space Cadet
geometry, native score panel and menus; the free artwork is explicitly labeled.
Phone/table and Coming soon screenshots are generated by the browser suites.
