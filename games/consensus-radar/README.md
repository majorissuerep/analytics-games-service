# Consensus Radar module

Reference game showing platform contract:

- `manifest.ts` — discovery metadata.
- `model.ts` — state/action/view types and scoring.
- `server.ts` — authoritative transitions and secret projection.
- `scales.ts` — game content.
- `client/ConsensusRadarGame.tsx` — visuals and local interaction only.
- `server.test.ts` — permissions, complete flow, scoring, privacy.
